# Ouroboros invocation boundary

Only invoke an ouroboros skill when the user explicitly enters that skill's ouroboros slash command.

Do not select or invoke ouroboros from semantic similarity, inferred intent, or an ordinary request to plan,
implement, or migrate work. Those requests are not ouroboros invocations, even when they resemble an ouroboros
workflow.

Without an explicit ouroboros slash command, do not start an ouroboros question flow, write ouroboros files, or
perform ouroboros git operations.
